# Data Structures Index

> Master data structures essential for algorithm design and performance optimization.

## Sequential Data Structures
- [[Arrays]] - Fixed-size, contiguous memory collections (O(1) access)
- [[Lists]] - Dynamic, ordered collections (O(1) append, O(n) insert)
- [[Linked Lists]] - Node-based collections (O(n) access, O(1) insert at head)

## Search Algorithms
- [[Linear Search]] - Simple sequential lookup
- [[Binary Search]] - Efficient lookup for sorted data
- [[Jump Search]] - Block-based sorted lookup
- [[Hash Lookup]] - Key-based lookup with hashing

## Sorting Algorithms
- [[Bubble Sort]] - Simple adjacent swap sorting
- [[Selection Sort]] - Repeated minimum selection
- [[Insertion Sort]] - Build sorted order incrementally
- [[Merge Sort]] - Divide and conquer sorting
- [[Quick Sort]] - Pivot-based partitioning

## Specialized Collections
- [[Stacks and Queues]] - LIFO/FIFO access patterns
- [[Dictionaries and HashSets]] - Key-value and set-based lookups (O(1) average)
- [[Trees]] - Hierarchical data structures (BST, AVL, etc.)
