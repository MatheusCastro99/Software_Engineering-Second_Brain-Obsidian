## Notes

This vault is organized for learning, revision, and practical software development study. It is intentionally structured like a second brain: small concepts first, then connections, then deeper systems thinking. It covers:
- C# and .NET programming fundamentals
- data structures, algorithms, and performance
- data modeling and querying
- web and API development
- AI guidance and multi-step task execution
- shipping software into production

Notes marked *(stub)* hold only a title and short description; they are placeholders for topics to be expanded.

## Note Format

Each topic note follows the same shape:

```markdown
---
tags:
  - topic-tag
category: <Folder Name>
related: Note A, Note B
---

# Title

Short definition.

## Sections with explanations, C# examples, and comparison tables

## Related Concepts
- [[Note A]] - why it is related
```

New notes are added to their folder's MOC and to the [StudyRoadmap.md](StudyRoadmap.md) so none are left unlinked.
