# From Editor to Execution

## Compiler vs Interpreter
### Interpreter
- executes the program line-by-line
	`(javascript, python)`
### Compiler
- translates the whole program into binary at once 
	`(C, C++)`
### Managed Code 
- uses an Intermediate language as a middle step, then sends that into the CLR, which after is translated into machine code
	 `(C#, Java)`
## Common Language Runtime (CLR)
- Translates intermediate language (assembly, .cll, .exe) into computer-readable machine code
## Code Path
- Written code on editor ->
- Build ->
- Intermediate language ->
- CLR ->
- Machine Code
